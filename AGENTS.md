# Agent Instructions

Before making any coding change in this repository, read and follow [`CODING_STANDARDS.md`](CODING_STANDARDS.md). It is the mandatory coding policy for all coding agents and human contributors.

Agents must inspect the relevant existing implementation and tests, preserve unrelated worktree changes, keep edits focused, run appropriate validation, and report any validation failures. The standards document is authoritative for architecture, C#/WPF conventions, testing, documentation, and safety requirements.
